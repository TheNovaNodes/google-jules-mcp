# Trigger pull_request workflow

This file documents the contents of the workflow that should run on
this branch. It exists only to force a new commit so that the
`pull_request` trigger of `.github/workflows/ci.yml` fires on the
already-open PR-28. The original workflow file
(`.github/workflows/ci.yml`, 1 005 B) is unchanged.

The CI workflow runs:
  - actions/checkout@v4
  - actions/setup-python@v5 with the matrix python-version
    [3.10, 3.11, 3.12]
  - pip install -e ".[dev]"
  - pip install black isort flake8 mypy
  - flake8 src/ tests/
  - black --check src/ tests/
  - isort --check-only src/ tests/
  - mypy src/
  - pytest tests/

After this trigger commit lands, `get_pull_request_status(28)` should
report a non-empty `statuses` array within ~30-90 seconds.
